## 第 2 章 while：一直跑，直到教练喊停

### 2.1 是什么 + 逐字符拆解

**画面：跑步机。** 教练举着秒表喊："**只要**还没满 5 圈，就继续跑！"——这就是 while：`只要条件成立，就把这件事再做一遍`。

```c
int i = 1;              // 起点：计数器拨到 1
while (i <= 5) {        // 门票检查：每圈开跑前先验票
    printf("第 %d 圈\n", i);
    i = i + 1;          // 步进：跑完一圈，计数器 +1
}
```

- `while` = "只要……就再来一遍"。
- `(i <= 5)` = 每圈开跑**之前**检查的条件，和 if 的括号一模一样的规矩（行尾**不加分号**）。
- `{ ... }` = 循环体：一圈要干的事。
- **三要素（灵魂，背下来）**：`起点`（i = 1）→ `条件`（i <= 5）→ `步进`（i = i + 1）。三者缺一，不是不转，就是疯转。

**执行顺序**：验票 → 跑圈 → 拨计数器 → 验票 → 跑圈 → 拨计数器……直到验票不合格，走人。i 数到 6 时，`6 <= 5` 不成立，循环结束。

⚠️ **一个反直觉的特点：先验票，再进场。** 如果一开始条件就不成立（比如 `int i = 10; while (i <= 5)`），循环体**一圈都不跑**，程序直接绕过去。这不是 bug，是设计。

### 2.2 【动手】累加器：1 加到 100 `sum_while.c`

**画面：存钱罐。** `sum` 是存钱罐，每跑一圈往里丢一个数——第 1 圈丢 1，第 2 圈丢 2……跑完 100 圈，罐子里就是 1+2+...+100。这个"罐子"套路，江湖人称**累加器**，以后每周都会用到。

```c
#include <stdio.h>

int main() {
    int sum = 0;            // 存钱罐，起手必须清零（W02 的坑：不初始化=垃圾值）
    int i = 1;              // 起点
    while (i <= 100) {      // 条件
        sum = sum + i;      // 把当前这圈的数丢进罐子
        i = i + 1;          // 步进
    }
    printf("1+2+...+100 = %d\n", sum);
    return 0;
}
```

```bash
gcc -Wall sum_while.c -o sum_while && ./sum_while
```

✅ 验收：打出 `1+2+...+100 = 5050`。

**逐行讲解**：`sum = sum + i;` 读作"把罐子里原有的数加上这圈的 i，再装回罐子"——`=` 是装进，不是等于（W02 老规矩）。`sum = 0` 这行省不得：罐子不先倒空，里面是上一位租客的垃圾。

### 2.3 【动手·事故演习】死循环：马达卡死了

把上面代码里的 `i = i + 1;` 删掉，重新编译运行。

✅ 你会看到屏幕疯狂刷"第 1 圈"，**永远停不下来**——这就是**死循环**：条件永远成立，马达卡死。三要素缺了"步进"，i 永远是 1，`1 <= 100` 永远为真。

**别慌，救命键**：在终端里按 `Ctrl + C`（主手册第 1 章的生存技巧）——程序立刻收尸。

把 `i = i + 1;` 加回去，跑通，**记进 mistakes.md**：症状"刷屏停不下来" / 病因"忘写步进" / 解法"补上 i = i + 1" / 教训"死循环三查：起点、条件、步进"。

### 2.4 本节坑与预防针

| 症状 | 病因 | 解法 |
|---|---|---|
| 屏幕疯狂刷屏停不下来 | 循环里忘写步进 | 补上 `i = i + 1;`；刷死了 `Ctrl + C` 收尸 |
| 累加结果是天文数字 | 累加器没初始化 | `int sum = 0;` 起手就写 |
| 循环一圈都没跑 | 初始条件就不成立 | 正常现象——while 先验票再进场；检查起点 |
| 条件永真死循环 | 把 `==` 写成 `=`（W03 复考） | 双等号；`-Wall` 会提醒 |

> 📒 生词：`while` `计数器` `累加器` `死循环`

## 第 3 章 for：数着圈跑

### 3.1 为什么有了 while 还要 for？

while 的三要素（起点、条件、步进）散落在代码的三行里，程序一长就找不到谁在哪。程序员发现：十次循环九次都是"数着圈跑"（从几数到几），于是造了个专用写法，把三要素**打包塞进一行**——这就是 for。

**画面：操场 10 圈。** 教练把规矩一次说完："**从第 1 圈开始，没满 10 圈就继续，每跑完一圈加 1。**"一句话，三要素全齐。

### 3.2 逐字符拆解（本周最重要的一段）

```c
for (int i = 1; i <= 100; i++) {
    sum = sum + i;
}
```

括号里三句话，用**分号**隔开（⚠️ 是分号不是逗号）：

```
for ( int i = 1 ; i <= 100 ; i++ )
      └─ 起点      └─ 条件    └─ 步进
      出发前只拨一次  每圈开跑前检查  每圈跑完拨一下
```

- `int i = 1` = **起点**：出发前把计数器拨到 1，整个循环只执行这一次。
- `i <= 100` = **条件**：每圈开跑前验票，不合格就下班。
- `i++` = **步进**：每圈跑完计数器 +1。**`i++` 就是 `i = i + 1` 的偷懒写法**，江湖专用，看到要认识。
- `{ ... }` = 循环体，一圈干的事。行尾**不加分号**（和 if 一样，多打了是坑，见 3.4）。

**执行顺序**（心里默念三遍）：`①起点 → ②验票 → ③跑圈 → ④步进 → ②验票 → ③跑圈 → ④步进 …… 直到 ② 不合格`。

> 💡 **一句话认识即可**：看到 `++i`（加号在前面）别慌，在 for 的这一格里它和 `i++` 效果一样，细微区别以后再细聊——**你的代码里一律写 `i++`**。

### 3.3 【动手】for 版 1 加到 100 `sum_for.c`

```c
#include <stdio.h>

int main() {
    int sum = 0;
    for (int i = 1; i <= 100; i++) {
        sum = sum + i;
    }
    printf("1+2+...+100 = %d\n", sum);
    printf("高斯公式对照: %d\n", 100 * 101 / 2);
    return 0;
}
```

```bash
gcc -Wall sum_for.c -o sum_for && ./sum_for
```

✅ 验收：两行都是 `5050`——第二行是数学家高斯小时候秒算这道题的公式 `n×(n+1)÷2`。电脑用蛮力一圈圈加，高斯用脑子一步到位，**结果一样，这就是你验算程序对不对的免费答案**。以后写循环程序，先想想"有没有已知答案可以对一对"。

### 3.4 for 还是 while？（30 秒选型指南）

| 场景 | 用谁 |
|---|---|
| 知道跑几圈：从 1 到 100、9 行 9 列、三次机会 | `for` |
| 不知道跑几圈：一直输入直到 -1、一直试直到猜对 | `while` |

一句话：**数得清用 for，数不清用 while。** 两者能互相改写，选顺手的。

### 3.5 本节坑与预防针

**坑 1：`for` 后面多打一个分号（if 的老坑在 for 这里复发）。**

```c
for (int i = 1; i <= 5; i++); {   // ← 这个 ; 让循环空转 5 圈
    printf("第 %d 圈\n", i);       // 这包东西只执行一次，还报未定义的错
}
```

**坑 2：差一错误（off-by-one）。** 想加到 100 写成 `i < 100`，结果只加到 99。**解法：动笔前手动数一遍边界**——从 1 数到 100 就写 `<= 100`；拿不准就代入最小的数试：`i=1` 该不该进？`i=100` 该不该进？

**坑 3：内外循环用同一个名字。** 预告第 5 章：嵌套循环里外层用 `i`、内层必须换个名（`j`），同一个名字会互相打架。

| 症状 | 病因 | 解法 |
|---|---|---|
| 循环体只执行一次 | `for(...)` 后多了 `;` | 删分号 |
| 少加/多加了一个数 | `<` 和 `<=` 用错 | 边界值手动数一遍（off-by-one） |
| 报错 i undeclared | 在循环外用了 for 里定义的 i | i 只在 for 的花括号里活着；外面要用就在外面定义 |

> 📒 生词：`for` `自增（i++）` `off-by-one（差一错误）`

## 第 4 章 break 与 continue：跳闸与跳圈

### 4.1 是什么（一对类比，一分钟分清）

跑圈跑到一半——

- `break` = **下课铃**：整件事到此为止，循环直接结束，后面的圈不跑了。
- `continue` = **跳过这一圈**：这一圈剩下的不跑了，**直接拨计数器进下一圈**，循环还在继续。

W03 你在 switch 里见过 `break`（跳出当前这层），循环里的 break 是同一个脾气：**跳出当前这一层**。

### 4.2 【动手】对比组：亲眼分清兄弟俩 `bc_demo.c`

```c
#include <stdio.h>

int main() {
    printf("continue 组: ");
    for (int i = 1; i <= 10; i++) {
        if (i == 5) {
            continue;        // 跳过 5 这一圈
        }
        printf("%d ", i);
    }

    printf("\nbreak 组: ");
    for (int i = 1; i <= 10; i++) {
        if (i == 7) {
            break;           // 到 7 全剧终
        }
        printf("%d ", i);
    }
    printf("\n");
    return 0;
}
```

```bash
gcc -Wall bc_demo.c -o bc_demo && ./bc_demo
```

✅ 验收：`continue 组: 1 2 3 4 6 7 8 9 10`（5 被跳过，后面继续）；`break 组: 1 2 3 4 5 6`（7 及以后全没了）。

### 4.3 实战王牌：哨兵模式（输入直到用户喊停）

不知道用户要输入几个数怎么办？**约定一个暗号（哨兵值）**，比如 -1：一直收，收到 -1 就 break 跳闸。

```c
while (1) {                 // 故意写成永远为真——出口交给里面的 break
    scanf("%lf", &score);
    if (score == -1) {      // 收到暗号
        break;              // 跳闸
    }
    // 正常处理 score
}
```

`while (1)` 读作"一直来"——1 永远为真，循环靠 break 主动收工。这是"数不清次数"场景的标配写法，练习 2 马上亲手用。

### 4.4 本节坑与预防针

| 症状 | 病因 | 解法 |
|---|---|---|
| 想跳过一圈，结果整个循环没了 | `break` 和 `continue` 用反了 | break=下课铃（全结束）；continue=跳过这圈 |
| `while(1)` 出不来 | 里面的 break 条件永远够不着 | 检查出口条件写对没；调试先打印看看 |
| 嵌套循环里 break 不听话 | 它只跳**当前这一层** | 外圈想停要另外想办法（❓悬念，以后深入） |

> 📒 生词：`break` `continue` `哨兵模式`

## 第 5 章 循环嵌套：圈里套圈

### 5.1 是什么 + 画面

**画面：钟表。** 时针走 1 格，分针转满 12 圈。嵌套循环就是这个节奏：**外圈每转 1 次，内圈要完整转完一整轮。**

日历也是：月份是外圈，日子是内圈——1 月的 31 天过完，才翻到 2 月。

### 5.2 【动手】先跑个小号的 `grid.c`

```c
#include <stdio.h>

int main() {
    for (int i = 1; i <= 3; i++) {          // 外圈：3 行
        for (int j = 1; j <= 4; j++) {      // 内圈：每行 4 列
            printf("(%d,%d) ", i, j);
        }
        printf("\n");                       // 内圈跑完一整轮，换行
    }
    return 0;
}
```

```bash
gcc -Wall grid.c -o grid && ./grid
```

✅ 验收：3 行 4 列的坐标方阵——`(1,1) (1,2) (1,3) (1,4)` 然后换行，直到 `(3,4)`。

**执行顺序拆解**：外圈 i=1 进门 → 内圈 j 从 1 跑到 4（完整一轮）→ 内圈结束 → 执行换行 → 外圈 i++ 变 2 → 内圈 j 又从 1 开始跑满……**铁律：外 i 内 j，两个名字不能撞**（撞了内层会把外层的计数器挡住，结果全乱）。

### 5.3 本节坑与预防针

| 症状 | 病因 | 解法 |
|---|---|---|
| 嵌套结果全乱/停不下来 | 内外层变量同名（都叫 i） | 外圈 `i`、内圈 `j`，江湖规矩 |
| 只有一行，没有换行 | `printf("\n")` 放错了圈 | 换行归外圈管，放在内圈**后面**、外圈里面 |
| 行列数不对 | 内外条件写反 | 记钟表：外圈慢（行/时针），内圈快（列/分针） |

> 📒 生词：`嵌套循环`

## 第 6 章 程序员基本功（本周增量，15 分钟）

### 6.1 循环调试：调小样 + 探照灯

循环一跑几百圈，printf 探照灯直接刷屏怎么办？老手两招：

1. **调小样**：把规模改小再调。1 加到 100 不对？先改成加到 5，手算答案 15 对一对，调通了再改回 100。**小样都对不了，大样必错。**
2. **探照灯打在关键变量上**：

```c
for (int i = 1; i <= 5; i++) {
    sum = sum + i;
    printf("【调试】第 %d 圈，i=%d，sum=%d\n", i, i, sum);   // 调通就删
}
```

每圈 i 和 sum 的变化一清二楚，第几圈开始不对的，一眼锁定。

### 6.2 死循环三查（保命清单）

程序卡死/刷屏，`Ctrl + C` 收尸后，按顺序查：

1. **步进写了吗？**（`i++` 在不在循环体里）
2. **条件会朝着"结束"变化吗？**（`i <= 100` 里 i 在涨，终会超 100 ✅；`i >= 1` 里 i 在涨，永远成立 ❌）
3. **条件里是不是把 `==` 写成了 `=`？**（W03 老坑，`-Wall` 会替你喊）

### 6.3 测试的直觉（循环版）

W03 的规矩升级：分支程序逐路踩，**循环程序踩边界**——循环 0 次（条件一开始就不成立）、1 次、正常次数，各试一遍。比如求和程序：输入 0 应得 0（一圈不跑），输入 1 应得 1，输入 100 应得 5050。

### 练习 1（跟做层）· 1 加到 N（for 版）

**要求**：用户输入一个整数 N，程序用 for 循环算出 `1+2+...+N`。

**手把手**：

① 建文件：VS Code 里【新建文件】，命名 `sum_n.c`（或内置终端 `touch sum_n.c`）。

② 敲代码：

```c
#include <stdio.h>

int main() {
    int n, sum = 0;
    printf("请输入 N: ");
    scanf("%d", &n);

    for (int i = 1; i <= n; i++) {
        sum = sum + i;
    }
    printf("1 加到 %d = %d\n", n, sum);
    return 0;
}
```

③ 编译运行：`gcc -Wall sum_n.c -o sum_n && ./sum_n`

✅ 验收：`100` → `5050`；`10` → `55`；`1` → `1`；`0` → `0`（一圈不跑，正常现象！）。

**逐行讲解**：和 3.3 的唯一区别是条件从写死的 `100` 变成变量 `n`——循环的圈数第一次由用户说了算。`sum = 0` 起手清零，雷打不动。

### 练习 2（半独立层）· 成绩平均分（哨兵模式实战）

**要求**：程序反复问成绩，用户输入 `-1` 表示结束；结束后打印"共 X 门，平均分 Y"（平均分保留 1 位小数）。⚠️ 一门都没输（直接输 -1）时，打"一门都没输"，**不许除以 0**（W03 的校验直觉）。

**💡 提示**：
- 骨架用 4.3 的哨兵模式：`while (1)` + 收到 -1 就 `break`。
- 需要两个"罐子"：`sum`（总分，double）和 `count`（门数，int）——**罐子都起手清零**。
- 平均分 = `sum / count`；sum 是 double，自动转换会救你（W02 6.3）。

**自检数据**：输入 `90 80 70 -1` → `共 3 门，平均分 80.0`；直接输入 `-1` → `一门都没输`。

<details><summary>参考答案（做完再点开）</summary>

```c
#include <stdio.h>

int main() {
    double score, sum = 0;
    int count = 0;

    printf("输入成绩，-1 结束: ");
    while (1) {
        scanf("%lf", &score);
        if (score == -1) {
            break;
        }
        sum = sum + score;
        count = count + 1;
    }

    if (count > 0) {
        printf("共 %d 门，平均分 %.1f\n", count, sum / count);
    } else {
        printf("一门都没输\n");
    }
    return 0;
}
```

**讲解**：`while (1)` 故意永真，出口全交给 `break`——这就是"数不清几次"场景的标配。`count > 0` 这道安检防的是除以 0（W03 检票员的同款直觉）。`sum / count` 里 sum 是 double、count 是 int，小规格自动升级大规格，结果是 double——W02 类型转换的老知识在发光。这个程序攒着：W06 学了数组，它会升级成成绩统计器。
</details>

### 练习 3（独立层）· 🏆 本周主项目：九九乘法表

**要求**：打印下三角九九乘法表，第 1 行 1 个式子，第 2 行 2 个……第 9 行 9 个。

**验收样子**（前几行）：

```
1x1=1
1x2=2   2x2=4
1x3=3   2x3=6   3x3=9
...
1x9=9   2x9=18  ...     9x9=81
```

**💡 提示**：
- 就是 5.2 的坐标方阵改的：外圈 `i` 管行（1~9），内圈 `j` 管列——但每行式子个数**等于行号**，所以内圈条件是 `j <= i`。
- 每个式子打 `jx i = 积`：`printf("%dx%d=%d\t", j, i, i * j);`——结尾的 `\t` 是 W02 学的制表符，负责对齐。
- 内圈跑满一轮，外圈记得 `printf("\n")` 换行（放错了圈就只打一行）。

**自检数据**：最后一行必须有 9 个式子且以 `9x9=81` 收尾；整张表共 45 个式子（1+2+...+9，用你的累加器心算验证）。

<details><summary>参考答案（做完再点开）</summary>

```c
#include <stdio.h>

int main() {
    for (int i = 1; i <= 9; i++) {
        for (int j = 1; j <= i; j++) {
            printf("%dx%d=%d\t", j, i, i * j);
        }
        printf("\n");
    }
    return 0;
}
```

**讲解**：核心就一行——内圈条件 `j <= i`。坐标方阵里内圈是固定的 `j <= 4`（每行一样多），九九表里内圈跟着外圈走（第几行就几个式子），**内圈条件引用外圈变量**，是嵌套循环最常用的一招。`x` 用字母 x 是为了对齐省心；想更好看可以换成 `×`，终端支持，但宽字符可能让 `\t` 略歪，随你。这个程序是"循环嵌套"的毕业证——截个图存好。
</details>

### 练习 4（挑战层·可选）· 星星三角

**要求**：打印 5 行直角星三角：

```
*
**
***
****
*****
```

**💡 提示**：和九九表同一个骨架——外圈 1~5 行，内圈每行的星星数等于行号。把 printf 里的式子换成 `*` 就行。做出来还想折腾？试试倒过来打（5 行星递减），只需要把外圈的起点/条件/步进整个反过来。

**自检数据**：共 5 行，星星总数 15 颗（1+2+3+4+5）。

<details><summary>参考答案</summary>

```c
#include <stdio.h>

int main() {
    for (int i = 1; i <= 5; i++) {
        for (int j = 1; j <= i; j++) {
            printf("*");
        }
        printf("\n");
    }
    return 0;
}
```

**讲解**：看出来了？它和九九表**逐行同构**，只是把 `%dx%d=%d\t` 换成 `*`。这就是学编程最值钱的体感：**套路复用**——同一个嵌套骨架，换上不同的"一圈干的事"，就是不同的程序。倒三角版本把外圈写成 `for (int i = 5; i >= 1; i--)`，起点变 5、条件变 `>= 1`、步进变 `i--`（就是 `i = i - 1` 的偷懒写法），三要素齐反。
</details>

## 第 9 章 本周避坑大全（一页速查，卡住了先翻这页）

| # | 症状 | 病因 | 解法 |
|---|---|---|---|
| 1 | 屏幕疯狂刷屏停不下来 | 循环里忘写步进（i++） | 补步进；刷死了 `Ctrl + C` 收尸 |
| 2 | 循环体只执行一次 | `for(...)` / `while(...)` 后多了 `;` | 删分号（if 的老坑复发） |
| 3 | 少加/多加了一个数 | `<` 和 `<=` 用错（off-by-one） | 边界值手动数一遍：1 和 n 该不该进 |
| 4 | 累加结果是天文数字 | 累加器没初始化 | `int sum = 0;` 起手就写 |
| 5 | 条件永真死循环 | 条件里 `==` 写成 `=` | 双等号；`gcc -Wall` 会喊（W03 复考） |
| 6 | 嵌套循环结果全乱 | 内外层变量同名 | 外圈 `i`、内圈 `j`，铁律 |
| 7 | 只打一行/不换行 | `printf("\n")` 放错了圈 | 换行归外圈管：内圈后、外圈内 |
| 8 | 输入程序卡着不动 | 出口条件够不着 | 哨兵模式：`while(1)` + 收到暗号 `break` |
| 9 | 想跳过一圈结果循环全没了 | break / continue 用反 | break=下课铃；continue=跳过这圈 |
| 10 | 九九表对不齐 | 没用 `\t` | 每个式子结尾 `\t`（W02 转义字符复考） |
| 11 | 大数相乘变负数 | int 溢出（约 21 亿上限） | 复考 W02：大数上 `long long` + `%lld` |
| 12 | 改了代码结果没变 | 没保存 | `Ctrl + S`（老坑定期复查） |

## 附录 · 本周代码骨架与速查卡

**while 骨架（数不清次数）：**

```c
#include <stdio.h>

int main() {
    int i = 1;              // 起点
    while (条件) {           // 每圈开跑前验票
        // 一圈干的事
        i = i + 1;          // 步进（忘了 = 死循环）
    }
    return 0;
}
```

**for 骨架（数得清次数）：**

```c
for (int i = 起点; i <= 终点; i++) {
    // 一圈干的事
}
```

**哨兵骨架（收到暗号才收工）：**

```c
while (1) {
    scanf(...);
    if (收到暗号) {
        break;
    }
    // 正常处理
}
```

**嵌套骨架（外 i 内 j）：**

```c
for (int i = 1; i <= 行数; i++) {
    for (int j = 1; j <= 每行个数; j++) {
        // 一格干的事
    }
    printf("\n");           // 换行归外圈
}
```

**速查卡（截图存手机）：**

```
编译：gcc -Wall xx.c -o xx && ./xx
三要素：起点 → 条件 → 步进，缺一不是不转就是疯转
for：数得清用；while：数不清用；哨兵：while(1)+break
break = 下课铃（全结束）  continue = 跳过这一圈
i++ = i = i + 1 的偷懒写法；i-- 同理
嵌套铁律：外 i 内 j；换行归外圈
死循环救命：Ctrl + C；然后三查：步进/条件/==写成=
调试：调小样（100 改 5）+ printf 探照灯打关键变量
```
