## 第 1 章 毕业项目亮相：规格说明书（15 分钟）

### 1.1 这台机器长什么样

开机后看到一个菜单，选功能、输数字、出结果，**算完一题回菜单接着算**，直到你选 0 下班：

```
===== 命令行计算器 =====
1.加  2.减  3.乘  4.除
5.历史记录  0.退出
请选择: 1
请输入两个数（空格隔开）: 3 5
结果: 8.00
（回到菜单……）
请选择: 5
#1: 8.00
请选择: 0
再见！
```

**功能规格（五条，条条对应你学过的器官）**：

| # | 功能 | 用的哪周的积木 |
|---|---|---|
| 1 | 菜单循环：算完回菜单，选 0 才退出 | W04 循环（哨兵模式） |
| 2 | 四则运算：加减乘除，switch 分发 | W03 分支 + W05 函数 |
| 3 | 除零拦截：除以 0 打提示，不许崩 | W03 判断（边界） |
| 4 | 非法选项拦截：输 9 打"没这个选项" | W03 判断（校验） |
| 5 | 历史记录：每次结果入账，选 5 查账 | W06 数组 + 计数器 |

### 1.2 开发方式：先能跑，再能算，再好用（分版本迭代）

新手做大项目最大的死法：**想一口吃成胖子，一百行写完才编译，满屏报错直接崩溃。** 职业程序员的做法是**分版本**：

```
v0  骨架版：菜单能显示、能退出、非法选项能拦（没有任何计算功能）
v1  运算版：+ 四则运算 + 除零拦截（能算了）
v2  完整版：+ 历史记录（能查账了）＝ 本周主项目
v3  加分版：+ 平方根（挑战层·可选）
```

**每个版本都是能跑的完整程序**，只是功能多少的区别。每完成一版：编译 → 跑 → 测 → commit。永远不让"写了一堆跑不起来"的情况存在——这就是大项目的保命心法。

## 第 2 章 把大项目拆小：函数分工图（15 分钟）

### 2.1 设计先行：main 是目录页

W05 的规矩本周是铁律：**main 里不许塞细枝末节。** 先把整台机器拆成零件，每个零件一个函数：

```
show_menu()            打印菜单（只干活不带货 → void）
calc(op, a, b)         按 op 算一笔，带回结果（double 带回货）
main()                 目录页：菜单循环 + 收选择 + 校验 + 喊函数 + 记账
```

⚠️ 设计决策，想三秒再往下看：**"收两个数"和"记账"为什么不单独包函数？**——因为它们各只有两三行，包一层反而绕。**函数是为"复用"和"让 main 变瘦"服务的，不是越多越好。** 这个判断力比语法重要。

### 2.2 注释先行：全中文骨架（你的定型方法）

动手之前，先写这个中文骨架，读顺——**这就是 v0 的设计图**：

```c
// show_menu 函数：打印菜单（5 行 printf）

// calc 函数：收 op/a/b，switch 按 op 算，return 结果

// main：
//   准备：history 数组（100 格 double）+ count = 0
//   主循环 while (1)：
//     显示菜单，收选择
//     选 0 → 说再见，break
//     选 5 → 有记录就逐条打印，没有就打"还没有"，continue
//     选 1~4 之外 → "没这个选项"，continue
//     收两个数
//     选除法且除数是 0 → 提示，continue
//     喊 calc 算，接货，打印结果（%.2f）
//     结果存入 history[count]，count + 1
```

读一遍，能顺下来吗？顺了，后面三天就是**逐段翻译**；不顺，卡在哪行就问哪行——这就是注释先行的价值：**把"想不清楚"和"写不出来"分开解决。**

## 第 4 章 本周"练习" = 项目三个版本（分层递进）

> 这周的练习就是项目本身，分四层。**每完成一个版本：跑通 → 过测试清单 → commit 存档。**

### 练习 1（跟做层）· v0 骨架版 `calc.c`：先能跑

**要求**：菜单能显示、能退出、非法选项能拦。没有任何计算功能——选 1~5 都打"待实现"。

**手把手**：

① 建文件 `calc.c`，按 2.2 的中文骨架，先翻译 show_menu 和主循环：

```c
#include <stdio.h>

void show_menu() {
    printf("\n===== 命令行计算器 =====\n");
    printf("1.加  2.减  3.乘  4.除\n");
    printf("5.历史记录  0.退出\n");
    printf("请选择: ");
}

int main() {
    while (1) {
        int choice;
        show_menu();
        scanf("%d", &choice);

        if (choice == 0) {
            printf("再见！\n");
            break;
        }
        if (choice < 1 || choice > 5) {
            printf("没这个选项\n");
            continue;
        }
        printf("【功能 %d 待实现】\n", choice);
    }
    return 0;
}
```

② `gcc -Wall calc.c -o calc && ./calc`

✅ 验收：菜单出现；输 `9` → 没这个选项；输 `1` → 待实现；输 `0` → 再见，程序结束。

③ 测试清单过一遍（正常/边界/非法），然后：

```bash
git add . && git commit -m "W08 计算器 v0：菜单骨架" && git push
```

**逐行讲解**：`while (1)` + 出口 break，W04 哨兵模式原味；`continue` = 跳过本轮回菜单（W04：跳过这一圈）；两个 if 的分工——第一个管"下班"，第二个管"安检"。**骨架先立住，后面只是往里填肉。**

### 练习 2（半独立层）· v1 运算版：能算了

**要求**：在 v0 基础上，把"待实现"换成真功能——新增 `calc` 函数（switch 分发四则），收两个数，打结果，除零拦截。

**💡 提示**：
- `calc` 写在 main 上面：`double calc(int op, double a, double b)`，里面 switch 四个 case 各 return 一行；switch 后面补一句 `return 0;`（到不了的兜底，防 `-Wall` 喊）
- 收数：`double a, b; scanf("%lf %lf", &a, &b);`（两个 `&`，都别漏）
- 除零守卫放在**喊 calc 之前**：`choice == 4 && b == 0` → 提示 + `continue`
- ⚠️ 守卫里是 `b == 0` 双等号——写成 `=` 你 W03 的坑就在毕业项目里直播

**自检数据**：选 1 输 `3 5` → `8.00`；选 3 输 `2.5 4` → `10.00`；选 4 输 `6 2` → `3.00`；选 4 输 `6 0` → `不能除以 0`（程序不崩，回菜单）。

<details><summary>参考答案（做完再点开）</summary>

```c
#include <stdio.h>

void show_menu() {
    printf("\n===== 命令行计算器 =====\n");
    printf("1.加  2.减  3.乘  4.除\n");
    printf("5.历史记录  0.退出\n");
    printf("请选择: ");
}

double calc(int op, double a, double b) {
    switch (op) {
        case 1: return a + b;
        case 2: return a - b;
        case 3: return a * b;
        case 4: return a / b;
    }
    return 0;               // 兜底：菜单已校验，到不了；防 -Wall 喊
}

int main() {
    while (1) {
        int choice;
        show_menu();
        scanf("%d", &choice);

        if (choice == 0) {
            printf("再见！\n");
            break;
        }
        if (choice == 5) {
            printf("【历史记录待 v2 实现】\n");
            continue;
        }
        if (choice < 1 || choice > 5) {
            printf("没这个选项\n");
            continue;
        }

        double a, b;
        printf("请输入两个数（空格隔开）: ");
        scanf("%lf %lf", &a, &b);

        if (choice == 4 && b == 0) {
            printf("不能除以 0\n");
            continue;
        }

        double result = calc(choice, a, b);   // 货要伸手接！
        printf("结果: %.2f\n", result);
    }
    return 0;
}
```

**讲解**：`calc` 里每个 case 直接 `return`——return 自带下班属性，所以**不需要 break**（W03 的 break 是防穿透，return 已经跳出整个函数了，这一手叫"return 代替 break"，认识即可）。`double result = calc(...)`——伸手接货，不接就白送（你的老坑值班）。
</details>

跑通、过测试清单，存档：`git commit -m "W08 计算器 v1：四则运算+除零拦截" && git push`

### 练习 3（独立层）· 🏆 本周主项目：v2 完整版（+ 历史记录）

**要求**：在 v1 基础上实现选 5——每次计算结果存入 `history` 数组，选 5 时逐条打印账目。

**规格**：
- `double history[100];` + `int count = 0;`（**起手清零**，你的肌肉）
- 每算出一笔：`history[count] = result; count = count + 1;`
- 选 5：`count == 0` 打"还没有计算记录"；否则循环打印 `#序号: 结果`
- ⚠️ **容量守卫**：存之前判断 `count < 100`，满了打"历史记录已满"——数组越界是论文 01 号样本（CWE-121）的原罪，毕业项目不许带

**自检数据**：连算三题（3+5 / 10-4 / 2.5×4）→ 选 5 应见 `#1: 8.00  #2: 6.00  #3: 10.00`；一题没算直接选 5 → `还没有计算记录`。

<details><summary>参考答案（做完再点开）</summary>

```c
#include <stdio.h>

void show_menu() {
    printf("\n===== 命令行计算器 =====\n");
    printf("1.加  2.减  3.乘  4.除\n");
    printf("5.历史记录  0.退出\n");
    printf("请选择: ");
}

double calc(int op, double a, double b) {
    switch (op) {
        case 1: return a + b;
        case 2: return a - b;
        case 3: return a * b;
        case 4: return a / b;
    }
    return 0;
}

int main() {
    double history[100];
    int count = 0;

    while (1) {
        int choice;
        show_menu();
        scanf("%d", &choice);

        if (choice == 0) {
            printf("再见！\n");
            break;
        }
        if (choice == 5) {
            if (count == 0) {
                printf("还没有计算记录\n");
            } else {
                for (int i = 0; i < count; i++) {
                    printf("#%d: %.2f\n", i + 1, history[i]);
                }
            }
            continue;
        }
        if (choice < 1 || choice > 5) {
            printf("没这个选项\n");
            continue;
        }

        double a, b;
        printf("请输入两个数（空格隔开）: ");
        scanf("%lf %lf", &a, &b);

        if (choice == 4 && b == 0) {
            printf("不能除以 0\n");
            continue;
        }

        double result = calc(choice, a, b);
        printf("结果: %.2f\n", result);

        if (count < 100) {              // 容量守卫：数组越界是天条
            history[count] = result;
            count = count + 1;
        } else {
            printf("（历史记录已满 100 条）\n");
        }
    }
    return 0;
}
```

**讲解**：`history` + `count` 就是 W06 成绩统计器的账本思路——数组管格子，count 管"用到第几格"。打印账目是标准队形 `i = 0; i < count; i++`（注意是 count 不是 100：只打**记过的账**）。main 站在目录页的高度：收、验、算、记，每段一句话能说清。
</details>

跑通、过完整测试清单，存档：`git commit -m "W08 计算器 v2：历史记录，完整版" && git push`

### 练习 4（挑战层·可选）· v3 加分版：平方根

**要求**：菜单加一项 `6.平方根`，选 6 只收**一个**数，打它的平方根（保留 2 位）；负数打"负数不能开平方"。

**💡 提示**：
- 程序开头加一行 `#include <math.h>`（借数学库的现成函数 `sqrt`）
- ⚠️ 编译命令要变：`gcc -Wall calc.c -o calc -lm`——尾巴上的 `-lm` 是"链接数学库"的意思（lm = link math），**漏了它编译报错**（认识即可：这是第一次借外部库，以后 `-l` 系列都是这个套路）
- 选 6 的流程和 1~4 不一样（只收一个数）——想清楚它该站在哪

**自检数据**：选 6 输 `2` → `1.41`；输 `-1` → `负数不能开平方`；输 `9` → `3.00`。

<details><summary>参考答案</summary>

在 v2 基础上改三处：

```c
#include <math.h>        // 加在 #include <stdio.h> 后面

// show_menu 里加一行：printf("6.平方根\n");

// main 里，校验范围改成 choice > 6，并在收数前插一段：
        if (choice == 6) {
            double a;
            printf("请输入一个数: ");
            scanf("%lf", &a);
            if (a < 0) {
                printf("负数不能开平方\n");
                continue;
            }
            printf("结果: %.2f\n", sqrt(a));
            continue;
        }
```

**讲解**：`sqrt` 是你借的第一个"别人家的函数"——和标准库的 printf 一家，只是住在 math.h 里，编译时要 `-lm` 打个招呼。答辩三问的③就是为它准备的：加一个功能要动哪几处（菜单文字 / 校验范围 / 主流程分支 / 编译命令），你现在身体已经有答案了。

### Day 2（函数与分发日）

1. 【找茬】switch 里四个 case 都忘了 break（v1 参考答案里为什么没写 break？）
2. 【预测】`continue` 在菜单循环里是什么意思？
3. 【补全】函数签名：`______ calc(int op, double ______, double b)`
4. 【微写作】手写 `show_menu()` 函数（5 行 printf，不看讲义）

<details><summary>Day 2 答案</summary>

### Day 3（守卫与类型日）

1. 【找茬】除零守卫写成 `if (choice == 4 && b = 0)`
2. 【预测】`printf("%.1f", 3 / 2);` 和 `printf("%.1f", 3.0 / 2);` 各打什么？
3. 【补全】记账两行：`history[______] = result;  count = ______;`
4. 【微写作】手写除零守卫那一段（含 continue），不看讲义

<details><summary>Day 3 答案</summary>

1. `b = 0` 是赋值（先把 b 清零，再拿 0 当条件 → 永远为假，守卫失效；真除零时程序崩）。双等号 `b == 0`
2. `1.0` 和 `1.5`——`3 / 2` 整数除法砍小数；类型看运算不看柜子（你的"柜子内容物不匹配"弱项专项）
3. `count`；`count + 1`
4. `if (choice == 4 && b == 0) { printf("不能除以 0\n"); continue; }`
</details>

### Day 4（数组与账目日）

1. 【找茬】打印账目：`for (int i = 1; i <= count; i++) printf("#%d: %.2f\n", i, history[i]);`
2. 【预测】一题没算就选 5，`count` 是几？该走哪个分支？
3. 【补全】容量守卫：`if (count ______ 100) { history[count] = result; count = count + 1; }`

<details><summary>Day 4 答案</summary>

1. 双错：从 0 开始、`i < count`（off-by-one 复考：从 1 起漏 `#1`，`<= count` 越界摸 `history[count]`——还没记账的格子）
2. 0；`count == 0` 分支，打"还没有计算记录"
3. `<`
4. 对照练习 3 参考答案的选 5 段——写完对一遍；序号显示用 `i + 1`（人数 1 起）
</details>

### Day 7（验收预热日）

1. 【综合找茬】（3 错）：

## 第 7 章 本周避坑大全（一页速查 · 综合版）

| # | 症状 | 病因 | 解法 |
|---|---|---|---|
| 1 | scanf 后程序崩/变量没变 | 漏 `&`（两个数要两个 `&`） | `scanf("%lf %lf", &a, &b);` |
| 2 | 选什么都直接退出 | `if (choice = 0)` 赋值 | `==` 双等号（W03 一级坑） |
| 3 | 除零守卫形同虚设 | `b = 0` 写成赋值 | `b == 0`；守卫放在喊 calc 之前 |
| 4 | 菜单回不来/功能不循环 | 忘了 `continue` 或循环结构错 | 校验失败 → continue 回菜单顶 |
| 5 | 结果拿不到/拿到垃圾 | 没接返回值 | 货要伸手接：`double result = calc(...);` |
| 6 | switch 后 `-Wall` 喊 control reaches end | 缺兜底 return | switch 后补 `return 0;` |
| 7 | 账目从 #0 开始/末尾多一行垃圾 | 循环 `i = 1` 或 `i <= count` | 标准队形 `i = 0; i < count; i++`，显示用 `i + 1` |
| 8 | 存了 101 条后程序崩 | 没做容量守卫 | 存之前 `if (count < 100)`（越界是天条） |
| 9 | 整数除法小数被砍 | `3 / 2` 双双是 int | 至少一边小数；项目里全程 double 没这坑 |
| 10 | 加了 sqrt 编译报 undefined reference | 漏了 `-lm` | `gcc -Wall calc.c -o calc -lm` |
| 11 | push 失败 | 网络/没 commit | 先 commit；网络按 W07 预案（科学上网/443） |
| 12 | 一百行才编译，满屏报错崩溃 | 贪心一口吃成胖子 | 小步快跑：5~10 行一编译；回第 3 章 |
