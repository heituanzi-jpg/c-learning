## 第 2 章 数组：一整排连号柜子

### 2.1 是什么 + 逐字符拆解

```c
int scores[5];
```

- `int` = 每个格子的规格：这排柜子每格都装 int。
- `scores` = 整排柜子**共用的标签**（一个名字管一排）。
- `[5]` = **连号 5 个格子**。

这一行 = 给我来一排 5 连号的 int 柜子，统共叫 scores。

**⚠️ 本周第一大反直觉：编号从 0 开始。**

```
scores[0]  scores[1]  scores[2]  scores[3]  scores[4]
 第 1 格     第 2 格     第 3 格     第 4 格     第 5 格
```

第 1 格叫 `scores[0]`，第 5 格叫 `scores[4]`——**没有 `scores[5]`！** 为什么从 0 数？因为下标的真实含义是"**从排头往前走几步**"：排头自己走 0 步，下一格走 1 步。这和楼层的"1 楼 = 地面层（走 0 层楼梯）"一个道理。先当规矩背，用一周就顺了。

### 2.2 怎么用：定义时初始化 + 下标存取

```c
int scores[5] = {80, 90, 70, 85, 95};   // 租一排 + 顺手装满（好习惯，和变量初始化同款）

scores[0] = 60;          // 把第 1 格换成 60
printf("%d\n", scores[4]); // 看第 5 格：95
```

`scores[i]` 里中括号读作"第 i 号格子"。**i 可以是变量**——这就是数组和 for 循环成为天生搭档的原因：循环变量 i 正好当编号用。

### 2.3 【动手】成绩入账 `array1.c`

```c
#include <stdio.h>

int main() {
    int scores[5] = {80, 90, 70, 85, 95};

    for (int i = 0; i < 5; i++) {
        printf("第 %d 门: %d\n", i + 1, scores[i]);
    }
    return 0;
}
```

```bash
gcc -Wall array1.c -o array1 && ./array1
```

✅ 验收：五行，第 1 门 80 …… 第 5 门 95。

**逐行讲解**：`for (int i = 0; i < 5; i++)` 是数组遍历的**标准队形**——从 0 开始、`< 5`（不是 `<= 5`！）、每次 +1。打印时用 `i + 1` 显示"第几门"（人数 1 起，电脑数 0 起，各数各的）。这个队形本周要敲十几遍，敲到不看也会。

### 2.4 【动手·事故演习】越界：摸了别人家的柜子 `oob.c`

```c
#include <stdio.h>

int main() {
    int a[3] = {1, 2, 3};
    printf("%d\n", a[2]);   // 合法：第 3 格
    printf("%d\n", a[3]);   // 越界！下标只有 0/1/2
    return 0;
}
```

✅ 验收：第一行 `3`；第二行是一个**垃圾值**（可能是 0，可能是天文数字，每次跑还可能不一样——`-Wall` 都不一定喊）。

⚠️ **注意：越界不报错，打出垃圾——这正是"碰巧对 ≠ 对"的数组版。** 你的论文数据集里，01 号样本（CWE-121 栈缓冲区溢出）和 08 号样本（CWE-193 差一错误）就是这件事的正式名字。规矩一句话：**合法下标永远是 `0 ~ 个数-1`，背成肌肉。**

### 2.5 本节坑与预防针

| 症状 | 病因 | 解法 |
|---|---|---|
| 打出垃圾值/程序崩 | 下标越界（`a[5]` 摸第 6 格） | 下标 0 ~ n-1；边界三问数组版（5.2） |
| 第一格没打印/最后一格乱码 | 循环从 1 开始、或 `i <= n` | 标准队形：`i = 0; i < n; i++` |
| 数组里全是垃圾 | 只定义没初始化 | 顺手 `= { ... }`；或 `{}` 没写满的格子会自动补 0（只定义不初始化才是垃圾） |

> 📒 生词：`越界`

## 第 3 章 sizeof 与数组进函数：这排柜子多大？

### 3.1 sizeof 量整排柜子

W02 你用 `sizeof` 量过单个柜子的规格；现在量整排：

```c
int a[10];
printf("%zu\n", sizeof(a));      // 40：整排 10 格 × 每格 4 字节
printf("%zu\n", sizeof(a[0]));   // 4：一格的大小
printf("%zu\n", sizeof(a) / sizeof(a[0]));  // 10：格子个数 = 总大小 ÷ 单格大小
```

`sizeof(a) / sizeof(a[0])` 是"**数组有几个格子**"的标准算法——整排重量除以单格重量，照背下来。

### 3.2 【动手·事故演习】sizeof 陷阱：进了函数就失灵 `sizeof_trap.c`

数组传给函数后，再拿 sizeof 量，量出来的东西会让你怀疑人生：

```c
#include <stdio.h>

void try_measure(int arr[]) {
    printf("函数里 sizeof(arr) = %zu\n", sizeof(arr));
}

int main() {
    int a[10];
    printf("main 里 sizeof(a) = %zu\n", sizeof(a));
    printf("main 里个数 = %zu\n", sizeof(a) / sizeof(a[0]));
    try_measure(a);
    return 0;
}
```

```bash
gcc -Wall sizeof_trap.c -o sizeof_trap && ./sizeof_trap
```

✅ 验收：`40`、`10`、然后函数里是 **`8`**——不是 40！

⚠️ 编译时 `-Wall` 会刷出一条 warning：`will return size of 'int *'`——它在提醒你"这里量到的是指针的大小"。**看到别慌，这个实验要的就是它**（老规矩：warning 是提醒，error 才拦路；而这条提醒正好在剧透下一节的答案）。

### 3.3 为什么失灵？——W05 的知识直接接管

**数组传给函数，传的不是整排柜子，是这排柜子的门牌号**（数组名 = 排头柜子的地址）。所以函数里的 `arr` 实际上是一个**指针**（W05 学的"装门牌号的柜子"），`sizeof(arr)` 量的是**门牌号本身的大小**（64 位系统 = 8 字节），跟整排柜子多大毫无关系。

推论一：**规矩——数组进函数，个数必须另带一个参数。**

```c
int sum_array(int arr[], int n) {   // arr 是门牌号，n 是格子个数，两个都要
    int sum = 0;
    for (int i = 0; i < n; i++) {
        sum = sum + arr[i];
    }
    return sum;
}
```

调用：`sum_array(scores, 5);`——数组名直接递进去（不加 `&`，它本来就是门牌号）。

推论二（细品）：W05 说"函数改不动你的变量（值传递）"，但**数组是例外**——函数拿到门牌号就能上门改原件：

```c
void zero_first(int arr[], int n) {
    arr[0] = 0;              // 顺门牌号上门，main 里的数组真的变了
}
```

这不是新知识，是 W05 `*p = 21` 的数组形态：**复印件改不动，门牌号能上门。**

### 3.4 本节坑与预防针

| 症状 | 病因 | 解法 |
|---|---|---|
| 函数里算个数结果离谱 | sizeof 陷阱：量的是门牌号（8） | 个数另带参数 `n` |
| 以为数组传函数改不动原件 | 和值传递记混了 | 数组传的是门牌号，**改得动**，写函数时别误伤 |
| `sum_array(&scores, 5)` 画蛇添足 | 以为数组也要 `&` | 数组名本身是门牌号，直接递 |

> 📒 生词：`sizeof 陷阱`

## 第 4 章 字符串：一排 char 柜子 + 一面结束旗

### 4.1 是什么 + 逐字符拆解

```c
char name[] = "kay";
```

- `char` = 每格装一个字符（W02：字符本质是数字，ASCII）。
- `name[]` = **不写个数**：让编译器自己数，数完**自动多留一格**。
- `"kay"` = 双引号包起来的一串字符（字符串）。

实际租了 **4 格**：`'k'` `'a'` `'y'` `'\0'`。

**`\0` 是"到此结束"的结束旗**（ASCII 编号 0 的特殊字符）：`printf` 打印字符串时从排头开始，见到 `\0` 收队。没有这面旗，打印就会一路冲出你的柜子，打出别人家的乱码。

### 4.2 【动手】眼见为实 `str1.c`

```c
#include <stdio.h>

int main() {
    char name[] = "kay";
    printf("整串打印: %s\n", name);
    printf("占 %zu 格\n", sizeof(name));
    printf("逐个走: ");
    for (int i = 0; name[i] != '\0'; i++) {
        printf("%c.", name[i]);
    }
    printf("\n");
    return 0;
}
```

```bash
gcc -Wall str1.c -o str1 && ./str1
```

✅ 验收：`整串打印: kay`；`占 4 格`（3 个字符 + 1 面旗）；`逐个走: k.a.y.`

**讲解**：`%s` 是字符串占位符；循环条件 `name[i] != '\0'` 读作"**没走到结束旗就继续**"——这是字符串遍历的标准队形，和数组的 `i < n` 并列背下来。

### 4.3 scanf 读字符串：& 铁律的第一个补丁

```c
char name[20];
scanf("%s", name);        // ⚠️ 注意：没有 &！
printf("你好, %s\n", name);
```

W02 的铁律是"scanf 见变量就 `&`"，今天打补丁：**读字符串不加 `&`。**

为什么？用 W05 的知识自己推：scanf 要门牌号上门放东西；`age` 是普通变量，要 `&age` 取门牌号；而**数组名 `name` 本身就是门牌号**（3.3 刚学），再写 `&` 是画蛇添足。**`&` 铁律的补丁，是你用指针知识自己推出来的——从背规矩到懂规矩，就在这一步。**

⚠️ 两个安全提醒：
1. `scanf("%s")` **不问柜子多大**，用户输多了就溢出到别人家（论文 01 号样本 CWE-121 的同款现场）。够用规矩：**柜子开大一点（20 格起步），输入别超过格子数 - 1**（留一格给 `\0`）。更安全的 `fgets` 是 ❓悬念，以后学。
2. `%s` **遇到空格就收队**——输 `kay gu` 只收进 `kay`。想让一整行都进来，也是 `fgets` 的悬念。

### 4.4 本节坑与预防针

| 症状 | 病因 | 解法 |
|---|---|---|
| 编译警告/打印乱码 | `char s[5] = "hello";` 装不下（5 字符 + 旗 = 6 格） | 格子数 ≥ 字符数 + 1；或 `[]` 让编译器数 |
| 字符串打出一串乱码尾巴 | 手动逐格赋值后忘了放 `\0` | 逐格初始化时最后手动补 `'\0'` |
| 编译警告/行为怪 | `scanf("%s", &name)` 加了 `&` | 数组名本身是门牌号，不加 |
| 输多了程序崩/数据乱 | `%s` 不查长度，溢出 | 柜子开大，输入 ≤ 格子数 - 1 |
| `if (name == "kay")` 永远不成立 | `==` 比的是门牌号，不是内容 | 字符串不能 `==`；逐字符比，或等 `strcmp`（❓悬念） |

> 📒 生词：`字符串` `'\0'（结束符）`

## 第 5 章 程序员基本功（本周增量）

### 5.1 数组调试：把下标和值一起打

数组程序的探照灯打法：**下标 + 值一起打**，错位一眼可见：

```c
for (int i = 0; i < 5; i++) {
    printf("【调试】scores[%d] = %d\n", i, scores[i]);   // 调通就删
}
```

### 5.2 边界三问（数组版）

W05 的三问本周升级成数组形态，每写完一个数组函数问一遍：

```
① 第一格（[0]）和最后一格（[n-1]）都摸对了吗？
② 空数组 / 只有 1 格，会不会崩？（打擂台起手 arr[0] 时，n=0 就出事）
③ 下标表达式有没有 <= n？（越界不报错，是"碰巧对≠对"的数组版）
```

### 5.3 打擂台法：找最大/最小的标准套路

找最高分，人脑是一眼扫；电脑要一个个比，套路叫**打擂台**：

```c
int max = arr[0];                    // 先让 0 号当擂主
for (int i = 1; i < n; i++) {        // 从 1 号开始挨个挑战
    if (arr[i] > max) {
        max = arr[i];                // 挑战成功，新擂主
    }
}
```

⚠️ **擂主起手必须是 `arr[0]`，不是 0！** 起手 0，遇到全负成绩（`-5, -1, -8`），0 永远稳坐擂台，结果错得无声无息——这既是初始化坑的变种，也是边界坑（练习 2 专治它）。

### 练习 2（半独立层）· 打擂台：找最高分 `find_max.c`

**要求**：写 `int find_max(int arr[], int n)` 返回最大值；main 里用三组数据测试。

**💡 提示**：5.3 的擂台套路原样用；**擂主起手 `arr[0]`，挑战从 1 号开始**。

**自检数据**（三组全对才算过，后两组是边界）：
- `{3, 7, 2, 9, 5}` → **9**
- `{-5, -1, -8}` → **-1**（全负！起手 0 在这组翻车）
- `{4}` → **4**（只有一格，循环一圈不跑，擂主直接赢）

<details><summary>参考答案（做完再点开）</summary>

```c
#include <stdio.h>

int find_max(int arr[], int n) {
    int max = arr[0];               // 0 号当擂主
    for (int i = 1; i < n; i++) {
        if (arr[i] > max) {
            max = arr[i];           // 挑战成功，换擂主
        }
    }
    return max;
}

int main() {
    int a[5] = {3, 7, 2, 9, 5};
    int b[3] = {-5, -1, -8};
    int c[1] = {4};
    printf("%d\n", find_max(a, 5));
    printf("%d\n", find_max(b, 3));
    printf("%d\n", find_max(c, 1));
    return 0;
}
```

**讲解**：第二组是全负边界——起手 `arr[0]`（-5）才扛得住；第三组 `1 < 1` 不成立，循环零圈，擂主直接获胜（"先验票后进场"又一次自动兜底）。函数化的好处再现：三组测试三行 printf，不用输一遍数据测一遍。自问：为什么挑战从 `i = 1` 开始？（0 号已经在擂台上了，不用自己挑战自己。）
</details>

### 练习 3（独立层）· 🏆 本周主项目：成绩统计器 `stat.c`

W04 的哨兵平均分，本周升级成完全体——数据全留底，三项统计。

**要求**：
1. scanf 循环收 **5 门成绩**（double），存进数组
2. 三个函数：`calc_max`、`calc_min`、`calc_avg`（参数都是 `double arr[], int n`）
3. main 是目录页：只收数据、喊函数、打印三行汇报

**验收样子**：

```
请输入 5 门成绩: 90 80 70 85 95
最高分: 95.0
最低分: 70.0
平均分: 84.0
```

**自检数据**（两组全对才算过）：
- `90 80 70 85 95` → 最高 95.0 / 最低 70.0 / 平均 **84.0**
- `59.5 60 100 0 88` → 最高 100.0 / 最低 **0.0**（0 分要扛住：打擂台起手 arr[0]！）/ 平均 **61.5**

**💡 提示**：先注释先行写骨架；`calc_avg` 里 sum 是 double，`sum / n` 自动转换会救你（W02）；main 里收数据用 `for` + `scanf("%lf", &scores[i])`——数组的每一格是普通变量，**这里要 `&`**（和字符串不是一家人，别混）。

<details><summary>参考答案（做完再点开）</summary>

```c
#include <stdio.h>

double calc_max(double arr[], int n) {
    double max = arr[0];
    for (int i = 1; i < n; i++) {
        if (arr[i] > max) {
            max = arr[i];
        }
    }
    return max;
}

double calc_min(double arr[], int n) {
    double min = arr[0];
    for (int i = 1; i < n; i++) {
        if (arr[i] < min) {
            min = arr[i];
        }
    }
    return min;
}

double calc_avg(double arr[], int n) {
    double sum = 0;
    for (int i = 0; i < n; i++) {
        sum = sum + arr[i];
    }
    return sum / n;
}

int main() {
    double scores[5];
    printf("请输入 5 门成绩: ");
    for (int i = 0; i < 5; i++) {
        scanf("%lf", &scores[i]);
    }
    printf("最高分: %.1f\n", calc_max(scores, 5));
    printf("最低分: %.1f\n", calc_min(scores, 5));
    printf("平均分: %.1f\n", calc_avg(scores, 5));
    return 0;
}
```

**讲解**：三个函数共用一副队形，差别只有"比大小 / 比小大 / 全加一遍"——**套路复用**，换一格就是一题。main 6 行：收、算、打，目录页。注意 `&scores[i]`：数组的**格子**是普通 double 变量，scanf 上门要门牌号；而数组名传函数时不加 &——同一张嘴两种说法，第 3、4 章各管一段。
</details>

### 练习 4（挑战层·可选）· 大写转小写 `lower.c`

**要求**：`char s[] = "HeLLo"`，遍历这串字符，遇大写字母转小写，打印转换结果 `hello`。

**💡 提示**：W02 的 ASCII 复活——`'A'` 是 65、`'a'` 是 97，**大小写编号差 32**。判断大写：`s[i] >= 'A' && s[i] <= 'Z'`；转换：`s[i] = s[i] + 32`。循环条件用结束旗队形。

**自检数据**：`"HeLLo"` → `hello`；`"abc"` → `abc`（全小写原样通过，边界）；`"ABC"` → `abc`。

<details><summary>参考答案</summary>

```c
#include <stdio.h>

int main() {
    char s[] = "HeLLo";
    for (int i = 0; s[i] != '\0'; i++) {
        if (s[i] >= 'A' && s[i] <= 'Z') {
            s[i] = s[i] + 32;       // ASCII：大小写编号差 32
        }
    }
    printf("%s\n", s);
    return 0;
}
```

**讲解**：字符即数字（W02）在这里第一次变成工具：比较 `'A' <= s[i]` 是在比编号，加 32 是在改编号。数组传进内存就能改——`s[i] = ...` 直接改原件，因为你就站在柜子跟前。
</details>

打擂台：max = arr[0] 起手，1 号开始挑战
字符串：char s[] = "kay" 占 4 格（含 '\0' 结束旗）
scanf %s 不加 &；格子数 ≥ 字符数 + 1；%s 遇空格收队
老坑值班表：越界不报错（碰巧对≠对）/ scanf 引号只放占位符 / 货要伸手接
