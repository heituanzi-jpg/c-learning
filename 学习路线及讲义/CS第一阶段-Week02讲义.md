## 第 1 章 先建立直觉：程序到底在干嘛（5 分钟）

在学任何语法之前，先在脑子里装两个画面，后面所有知识都挂在这两个钉子上。

**画面一：程序 = 一张按顺序执行的清单。**
电脑是个一根筋的机器人，你写的代码就是它手里的购物清单：从第一行开始，做一行，往下一行，绝不跳步、绝不动脑。你 Week 01 的 hello.c 只有一件事："打印一行字"，它做完就下班。

**画面二：内存 = 一整面墙的储物柜。**
程序运行时需要"记住东西"——比如你输入的年龄。这些东西存放在内存里。内存你可以想象成超市门口一整面墙的储物柜，成千上万个格子。本周的核心就一件事：**怎么跟这面墙打交道**——怎么租一个柜子（变量）、怎么放东西进去（赋值和输入）、怎么把里面的东西拿出来看（输出）。

## 第 2 章 变量：贴了标签的储物柜

### 2.1 为什么需要变量？——从 hello world 的"无力感"说起

上周的程序只会说一句写死的话。它没法回答"你几岁"，因为它**没有地方存"你的回答"**。变量就是解决这个的：在储物柜墙上租一个格子，贴上标签，以后用标签存取东西。

### 2.2 定义变量：语法逐字符拆解

```c
int age;
```

就两个词，但每个都有讲究：

- `int` = 柜子的**规格**。int 是 integer（整数）的缩写，表示"这个柜子只装整数"。
- `age` = 柜子上的**标签**，你自己起的名字。
- `;` = 一句话说完了。C 语言每句话结尾都要有它，就像中文的句号。

这一行的意思是：**给我来一个装整数的柜子，标签叫 age。**

### 2.3 赋值与换值：= 不是"等于"

```c
int age;
age = 20;
```

`=` 在 C 语言里**不是"等于"**，读作"**装进**"：把右边的值，装进左边的柜子。上面第二行读作"把 20 装进 age"。

柜子里的东西可以换：

```c
int age = 20;   // 定义时顺手装值，这叫"初始化"，是好习惯
age = 21;       // 把旧的 20 倒掉，装进 21。现在柜子里是 21
```

> ⚠️ **新手第一魔咒**：把 `=` 读成"等于"。从今天起改口读"装进"。真正的"等于"长这样：`==`（两个等号），第 3 周才用，先有个印象。

两行还能合成一行：`int age = 20;`——租柜子的同时装东西。**以后定义变量，尽量都顺手初始化**，理由见 2.6 的坑。

### 2.4 命名规则与命名之道（科班考试不考，但拉开差距的地方）

**硬规则（违反就报错）：**

1. 只能由：字母、数字、下划线 `_` 组成
2. 第一个字符**不能是数字**（`2name` ❌，`name2` ✅）
3. 不能用 C 的"保留字"——就是语言自己已经占用的词，比如 `int`、`return`、`main`、`printf` 都不能当变量名
4. **区分大小写**：`age` 和 `Age` 是两个不同的柜子

**软规矩（不报错，但决定你像不像个程序员）：**

| 烂名字 | 好名字 | 为什么 |
|---|---|---|
| `a`, `b`, `x1` | `age`, `height`, `weight` | 三个月后你还认识它 |
| `nianling`（拼音） | `age`（英文） | 程序员的世界通用英文，顺便背单词 |
| `A`, `AGE` | `age`（全小写） | 变量名的江湖规矩：小写 + 下划线，如 `birth_year` |

> 💡 你以后每天写的代码都会传 GitHub，命名习惯就是你的脸面。从现在起，拼音命名一次都不许出现。

### 2.5 【动手】你的第一组变量

在 VS Code 里，到 `~/code/c-learning/week02/` 文件夹新建文件 `card.c`（终端里 `cd ~/code/c-learning/week02 && touch card.c`，然后 `code .` 打开），手敲：

```c
#include <stdio.h>

int main() {
    int age = 20;
    double height = 1.85;
    double weight = 77.5;

    printf("年龄: %d\n", age);
    printf("身高: %f 米\n", height);
    printf("体重: %f 公斤\n", weight);
    return 0;
}
```

终端里编译运行：

```bash
gcc card.c -o card && ./card
```

✅ 看到三行输出，但你会发现一个"丑点"：身高打出来是 `1.850000`——拖着 6 位小数的尾巴。别不爽，**记住这个不爽**，第 4 章我们亲手把它收拾成 `1.85`。

这 5 分钟里你已经用到了本周一半的知识：定义变量、初始化、三种类型、printf 占位符。剩下的都是细节。

### 2.6 本节三个坑（先打预防针）

**坑 1：变量没初始化就用。**

```c
int age;
printf("%d\n", age);   // 柜子里不是空的——是上一位租客留下的随机垃圾
```

租柜子时里面**不是空的**，是前任留下的随机数。所以：`int age = 0;` 养成随手初始化的习惯。

**坑 2：没定义就用。** `printf("%d", score);` 但你从没写过 `int score;`——编译报错：`error: 'score' undeclared`。翻译：**你用了不存在的柜子**。

**坑 3：同一个名字定义两次。** `int age = 20; int age = 21;`——同一个标签不能租两个柜子，报错 `redefinition`。想换值，直接 `age = 21;`（前面不带 int）。

## 第 3 章 数据类型：柜子的规格

### 3.1 为什么要有"类型"？

超市储物柜有小格、大格、行李柜——因为存手机和存行李箱需要的空间不一样。内存也一样：整数、小数、单个字符，占的空间和存法都不同。定义变量时写类型，就是告诉电脑："**给我多大、什么规格的柜子**"。

本周只需要三剑客：

| 类型 | 装什么 | 占位符 | 例子 |
|---|---|---|---|
| `int` | 整数（大约 ±21 亿） | `%d` | `int age = 20;` |
| `double` | 小数（双精度浮点数） | `%f` | `double height = 1.85;` |
| `char` | **一个**字符 | `%c` | `char grade = 'A';` |

### 3.2 int：整数柜

- 范围大约 -21 亿 ~ +21 亿，日常够用
- ⚠️ 装不了小数：`int x = 3.7;` 会把 3.7 的小数部分**直接砍掉**，x 变成 3（不是四舍五入！）

【动手·有趣的溢出实验】int 的柜子是有大小的，装满了会怎样？敲这段：

```c
#include <stdio.h>

int main() {
    int big = 2000000000;          // 20 亿，还没满
    printf("%d\n", big + big);     // 加一倍，超过 21 亿上限了
    return 0;
}
```

✅ 你会看到一个**负数**。柜子装不下，数据"溢出"绕了一圈变成负的——就像里程表转到 999999 再滚回 000000。现在只需记住一句话：**int 有上限，大约 21 亿。**（这个坑以后会在考研题里等你，今天先混个脸熟。）

### 3.3 double：小数柜

- 装小数，精度约 15~16 位有效数字，日常绰绰有余
- 它有个兄弟叫 `float`（单精度），**初学一律用 double**，别纠结，江湖共识
- 整除的坑和它有关，第 6 章详谈

### 3.4 char 的秘密：字符其实是数字

```c
char grade = 'A';
```

⚠️ 注意是**单引号**。`"A"`（双引号）是另一回事（字符串，第 6 周才学）。

秘密来了：**电脑根本不认识字母，char 柜子里存的其实是一个数字——字符的编号。** 这张对照表叫 ASCII 表，最常用的几个：

| 字符 | 编号 |
|---|---|
| `'0'` | 48 |
| `'A'` | 65 |
| `'a'` | 97 |

【动手·眼见为实】

```c
#include <stdio.h>

int main() {
    char grade = 'A';
    printf("作为字符看: %c\n", grade);
    printf("作为数字看: %d\n", grade);   // 会打出 65
    printf("A 的下一个: %c\n", grade + 1); // 会打出 B
    return 0;
}
```

✅ 看到 `A`、`65`、`B`。第三行能打出 B，正是因为字符本质是数字——`65 + 1 = 66 = 'B'`。**这个"字符即数字"的直觉，以后做考研题会救你。**

### 3.5 【动手】sizeof：看看你的柜子多大

`sizeof` 是个小工具，能量出某种类型占多少**字节**（byte，内存的基本单位，1 字节 = 8 个二进制位）：

```c
#include <stdio.h>

int main() {
    printf("int 占 %zu 字节\n", sizeof(int));
    printf("double 占 %zu 字节\n", sizeof(double));
    printf("char 占 %zu 字节\n", sizeof(char));
    return 0;
}
```

✅ 一般看到：int 4 字节、double 8 字节、char 1 字节。double 的柜子是 char 的 8 倍大——所以它能装下又长又精密的小数。（`%zu` 是 sizeof 专用的占位符，照抄即可。）

### 3.6 【拓展·10 分钟】二进制直觉：计算机只认 0 和 1

不用学进制转换（考研才细考，现在只要直觉）：

- 内存里每个小格子只能存两种状态：有电 / 没电 → 记作 1 / 0
- 所以电脑里的一切——数字、字符、图片、程序本身——最终全是 0 和 1 的排列
- 一个 char 是 8 个 0/1（1 字节），`int` 是 32 个 0/1 排成一队
- 为什么 int 上限是 21 亿左右？因为 32 个 0/1 最多能排出约 43 亿种组合，正负对半分

> 📝 生词打卡：`int` `double` `char` `ASCII` `溢出` `字节`。其中 ASCII 和溢出写进 glossary.md 时各配一句你自己的理解。

## 第 4 章 printf：让程序会说话

### 4.1 占位符：话里留个空，用变量填

```c
int age = 20;
printf("我今年 %d 岁\n", age);
```

读法：`%d` 是"**此处插入一个整数**"的占位符，双引号里是模板，逗号后面的 `age` 按顺序填进空里。打印出来：`我今年 20 岁`。

三种占位符对三种柜子，**对错了就打出乱码**：

| 柜子里是 | 占位符用 |
|---|---|
| int | `%d` |
| double | `%f` |
| char | `%c` |

一次可以填多个空，按顺序对号入座：

```c
printf("年龄 %d，身高 %f，等级 %c\n", age, height, grade);
```

### 4.2 %.2f：收拾那条小数尾巴

2.5 节留下的"不爽"：`%f` 默认打 6 位小数（`1.850000`）。解决办法是在 `%` 和 `f` 之间加精度控制：

| 写法 | 效果 | 例子（1.85） |
|---|---|---|
| `%f` | 默认 6 位小数 | 1.850000 |
| `%.2f` | 保留 2 位小数 | 1.85 |
| `%.1f` | 保留 1 位小数 | 1.9（会四舍五入！） |

⚠️ 注意：`%.1f` 会**四舍五入**。77.5 / (1.85×1.85) ≈ 22.644，用 `%.1f` 打出来是 `22.6`。

### 4.3 转义字符：打不出来的"特殊动作"

有些"字符"没法直接敲进代码里，用反斜杠 `\` 开头表示：

| 写法 | 作用 | 类比 |
|---|---|---|
| `\n` | 换行 | 按回车 |
| `\t` | 制表符（对齐用的大空格） | 按 Tab |
| `\\` | 打印一个反斜杠本身 | —— |
| `%%` | 打印一个百分号 | —— |

⚠️ 忘掉 `\n` 是新手日常：所有输出挤在一行。看到输出糊成一团，先检查 `\n`。

### 4.4 本节两个坑

**坑 1：占位符和类型不匹配。** 用 `%d` 打印 double 变量 → 打出天文数字乱码。**占位符必须和柜子规格对上。**

**坑 2：漏逗号。** `printf("%d %d", a b);`——变量之间漏了逗号，编译报错。报错信息里出现 `expected ','` 就是在说它。

## 第 5 章 scanf：让程序听你说话

### 5.1 基本用法

```c
int age;
printf("你几岁？");
scanf("%d", &age);
printf("你 %d 岁。\n", age);
```

逐行拆解：

1. 先打印一句提示，告诉用户该输入了
2. `scanf("%d", &age);`：程序**停下来等你打字**，你输入 `20` 回车，20 就被装进 age
3. 然后接着往下跑

⚠️ **注意 age 前面的 `&`——本周最大的坑，没有之一。**

### 5.2 & 是什么？（只讲够用版，原理第 5 周见）

`&age` 读作"age 的地址"——就是 age 这个储物柜的**门牌号**。

为什么 scanf 需要门牌号？打个比方：printf 是"把柜子里的东西拿出来看"，看一眼就行；scanf 是"**把东西放进柜子**"——它必须知道柜子**在哪**，才能把值送进去。`&` 就是取门牌号的动作。

**本周你只需要记住一条铁律：scanf 里，变量名前面一律加 `&`。忘了加 → 程序崩溃或行为诡异，而且报错信息你还看不懂（这就是它成为新手第一坑的原因）。**

> 📝 记进 glossary.md：`&（取地址）` ——大白话："变量的门牌号。scanf 要靠它找到柜子放东西。第 5 周学指针时再深入。"状态标 ❓，这是计划内的悬念。

### 5.3 一次读多个值

```c
double height, weight;   // 同类型的变量可以一行定义，逗号隔开
scanf("%lf %lf", &height, &weight);
```

⚠️ 两个细节：

1. **double 在 scanf 里用 `%lf`**（printf 里用 `%f`，别混）。这是历史原因，先死记：scanf 见 double 用 `%lf`。
2. 你输入时用**空格或回车**隔开两个数即可，比如敲 `1.85 77.5` 回车。

### 5.4 本节三个坑

**坑 1：忘 `&`。** 上面说过了，把它写进错题本的"一级通缉"位置。

**坑 2：在 scanf 的引号里画蛇添足。** `scanf("%d\n", &age);`——引号里那个 `\n` 会让程序行为变得很奇怪（要你多输点东西才肯走）。**规矩：scanf 的引号里只写占位符，别的什么都不写。**

**坑 3：用户乱输。** 你让他输年龄，他输了 `abc` → 程序行为诡异。本周先知道"会坏"，第 3 周学会判断后再收拾它。

## 第 6 章 运算符与表达式

### 6.1 算术五兄弟

| 运算符 | 作用 | 例子 | 结果 |
|---|---|---|---|
| `+` | 加 | `7 + 2` | 9 |
| `-` | 减 | `7 - 2` | 5 |
| `*` | 乘（不是 ×） | `7 * 2` | 14 |
| `/` | 除（**有坑，见 6.2**） | `7 / 2` | 3 |
| `%` | 取余数（只能用于整数） | `7 % 2` | 1 |

`%`（取余）是新手觉得怪、老手天天用的东西：`7 % 2` 读作"7 除以 2 的余数"，等于 1。两个经典用途，先混脸熟：

- **判断奇偶**：`n % 2` 等于 0 就是偶数（第 3 周配合 if 使用）
- **拆数字**：`123 % 10` 得到个位数 `3`

### 6.2 本周第二大坑：整数除法 5/2 = 2

【动手】亲眼看看：

```c
#include <stdio.h>

int main() {
    printf("%f\n", 5 / 2);       // 你期待 2.5
    printf("%f\n", 5.0 / 2);     // 对比组
    return 0;
}
```

✅ 第一行打出 `2.000000`，第二行打出 `2.500000`。

**为什么？** C 语言里，**整数 ÷ 整数，结果还是整数**——小数部分直接砍掉（不是四舍五入）。`5 / 2` 两边都是整数，电脑老老实实做整数除法，把 .5 扔了。

类比：5 个苹果分给 2 个人，每人 2 个（整数除法的结果），剩 1 个在桌上（`5 % 2` 的余数）。

**怎么破？** 让参与运算的至少一个是小数即可：`5.0 / 2`、`5 / 2.0`、或 `1.0 * 5 / 2` 都行。还有一个正规军写法叫"强制类型转换"，6.3 就讲。

⚠️ 最阴险的场景：**变量**。`int a = 5, b = 2;` 之后 `a / b` 还是整数除法——因为坑不坑取决于**变量的类型**，不取决于值。这条务必进 glossary.md。

### 6.3 类型转换

**自动转换（电脑悄悄干的）**：不同类型的数混在一起算，电脑自动把"小规格"升级成"大规格"再算。`5 / 2.0` 里 int 的 5 被自动升级成 double 的 5.0，所以结果是 2.5。

**强制转换（你命令它干的）**：在值前面加 `(类型)`，强行换装：

```c
int a = 5, b = 2;
printf("%f\n", (double)a / b);   // 把 a 临时当成 double → 2.500000
```

`(double)a` 读作"把 a 临时转换成 double"。这是处理"两个 int 变量相除想要小数"的标准解法，**BMI 计算器就要靠它**。

### 6.4 优先级：记不住，就打括号

`a + b * c` 先算乘后算加，和小学数学一样。但运算符一多谁记得住？**程序员的真实做法：拿不准就打括号。** `(a + b) * c` 清清楚楚。括号不要钱，可读性值钱。

### 6.5 复合赋值：懒人写法（认识即可）

```c
age = age + 1;   // 把 age 里的值加 1 再装回去
age += 1;        // 一模一样的意思，偷懒写法
```

`+=` `-=` `*=` `/=` 都是一家人。看到认识就行，写不写随你。

## 第 7 章 程序员的基本功（科班不太教，但决定你能走多远）

这一章和语法无关，但它是"讲义"和"视频"最大的区别——**视频教你知识，这一章教你不出事。**

### 7.1 注释与代码风格

**注释** = 写在代码里、给人看的话，电脑完全忽略。写法：`// 后面的都是注释，到本行结束`。

什么时候写？**写"为什么"，不写"是什么"。**

```c
double bmi = weight / (height * height);  // 身高单位是米，体重单位是公斤
```

好注释解释"身高为什么是米"这种代码里看不出来的事；烂注释是 `int age; // 定义一个年龄`——废话。

**缩进**：看本讲义所有代码，`{` 里的内容统一往后缩 4 个空格（VS Code 里按 Tab 自动缩）。缩进不是美观问题——层级一眼可见，括号漏没漏一眼可查。**代码歪七扭八的人，报错率是别人的三倍**，这是真理不是夸张。

### 7.2 读报错的方法论（三步定位法）

新手看到满屏英文报错就慌。其实报错的读法有固定套路，三步：

**第 1 步：只看第一条报错。** 编译器报错的毛病是"一个错，吓出一串"——后面的经常是第一条的连锁反应。修第一条，重编译，往往全消。

**第 2 步：找"文件名:行号"。** 报错长这样：

```
card.c:6:5: error: expected ';' before 'return'
```

`card.c:6:5` = 文件 card.c，第 6 行，第 5 个字符附近。翻译成人话：**第 6 行附近有问题**（注意是"附近"，缺分号这种错，真正的元凶常常在上一行）。

**第 3 步：读关键词猜意思。** 报错里的高频词就那几个，混个脸熟：

| 报错关键词 | 大概率是 |
|---|---|
| `expected ';'` | 缺分号（检查报错行的上一行） |
| `undeclared` | 用了没定义的变量名（拼写？忘定义？） |
| `redefinition` | 同名变量定义了两次 |
| `expected ','` | 漏逗号 |
| `implicit declaration` | 函数名拼错（比如 `Printf` 大写） |

**实战解剖**：把这段有错代码敲进去，编译，亲自读一遍报错：

```c
#include <stdio.h>

int main() {
    int age = 20
    printf("%d\n", age);
    return 0;
}
```

你会看到报错指向第 5 行（printf 那行），但真正的错在第 4 行末尾缺 `;`——**这就是"元凶在上一行"的现场教学。** 改好，跑通，把这条记进 mistakes.md。

### 7.3 printf 调试法：程序员的探照灯

程序结果不对，又看不出哪错？在关键位置插一句 printf，把变量的值打出来看：

```c
double c = (f - 32) * 5 / 9;
printf("【调试】算出来的 c = %f\n", c);   // 打完看一眼，找到问题就删掉
```

程序是个黑盒，printf 就是你往黑盒里打的探照灯。这个阶段你 90% 的调试就靠它，简单、粗暴、有效。

### 7.4 如何搜索问题（科班四年都不教的事）

遇到报错，老手和新手的差距不在智商，在**搜索关键词**。

- ❌ 菜鸟搜法：`c语言 程序出错 怎么办`（一屏的培训机构广告）
- ✅ 老手搜法：**把报错信息里最核心的一句原样复制** + 语言名，如：`expected ';' before 'return' c`

报错信息是全世界程序员共同的痛苦，你踩的坑 99% 有人踩过并且写了解答。优先看：Stack Overflow（英文）、博客园/CSDN（中文，质量参差，注意甄别）。

### 7.5 如何提问（问我和问 Kimi 都适用）

一个"好问题"有三件套，缺一件别人就得猜：

```
1. 我想干嘛（"我想输入身高体重算 BMI"）
2. 代码全文（不是截图描述，是代码本身）
3. 实际发生了什么（报错全文 / "打出来是 0.000000"）+ 我试过什么
```

以后问我问题，尽量带齐三件套——这不是客套，是在训练你工程师的核心技能：**把问题描述清楚，问题就解决了一半。**

> 💡 配 Kimi Code 使用（主手册第 6 章）：把三件套塞进咒语里，它比你自己瞎试快十倍。但记住三许三不许：它只能指路，代码必须你敲。

## 第 8 章 本周练习（分层设计，全部附参考答案与讲解）

> 规矩：跟做层手把手带；半独立层给提示；独立层只给要求和自检数据。**先自己做，做完再对答案。答案不是用来抄的，是用来对的——对不上的地方，就是你这周真正的收获。**

### 练习 1（跟做层）· 个人信息卡

**要求**：定义变量存年龄、身高、体重，打印成一张卡片。

**手把手**：

① 建文件：`cd ~/code/c-learning/week02 && touch info.c && code .`

② 敲代码（边看边想每一行在干嘛）：

```c
#include <stdio.h>

int main() {
    int age = 20;
    double height = 1.85;
    double weight = 77.5;

    printf("========== 个人信息卡 ==========\n");
    printf("年龄: %d\n", age);
    printf("身高: %.2f 米\n", height);
    printf("体重: %.1f 公斤\n", weight);
    printf("================================\n");
    return 0;
}
```

③ 编译运行：`gcc info.c -o info && ./info`

✅ 验收样子：

```
========== 个人信息卡 ==========
年龄: 20
身高: 1.85 米
体重: 77.5 公斤
================================
```

**逐行讲解**：`%.2f` 让身高保留 2 位小数（恰好打出 1.85）；`%.1f` 让体重保留 1 位。这两行就是 4.2 节的实战——那条 6 位小数的尾巴，亲手砍掉了。

### 练习 2（半独立层）· 温度转换器

**要求**：分两步——
① 固定值版：`F = 100` 写死，算出摄氏度打印；
② 输入版：改成 scanf 让用户输入 F。

**公式**：`C = (F - 32) * 5 / 9`

💡 提示：全部用 `double`；scanf 读 double 记得是 `%lf` 和 `&`。

**自检数据**：输入 `100` → 应得约 `37.78`；输入 `32` → 应得 `0`（冰点）。得到整数？回去看 6.2 节的坑。

<details>参考答案（做完再点开）</summary>

```c
#include <stdio.h>

int main() {
    double f, c;
    printf("请输入华氏温度: ");
    scanf("%lf", &f);
    c = (f - 32) * 5 / 9;
    printf("摄氏温度是 %.2f 度\n", c);
    return 0;
}
```

**讲解**：`f - 32` 里 32 是 int，但 f 是 double，自动转换救了你（6.3 节）；保险起见写 `32.0` 也行，意思完全一样。
</details>

### 练习 3（独立层）· 🏆 本周主项目：BMI 计算器

**要求**：程序依次问身高（米）、体重（公斤），算出 `BMI = 体重 ÷ (身高 × 身高)`，保留 1 位小数打印。

**验收样子**：

```
请输入身高(米): 1.85
请输入体重(公斤): 77.5
你的 BMI 是 22.6
```

**自检数据**：1.85m / 77.5kg → **22.6**；1.70m / 65kg → **22.5**。两个都对才算过。

🎁 彩蛋预告：第 3 周学会 if 之后，我们给它加上"偏瘦/标准/偏重"的自动判断。

<details>参考答案（做完再点开）</summary>

```c
#include <stdio.h>

int main() {
    double height, weight, bmi;
    printf("请输入身高(米): ");
    scanf("%lf", &height);
    printf("请输入体重(公斤): ");
    scanf("%lf", &weight);
    bmi = weight / (height * height);
    printf("你的 BMI 是 %.1f\n", bmi);
    return 0;
}
```

**讲解**：三个 double 变量一间"合租"的定义方式见 5.3 节；`height * height` 的括号保证了先算分母（6.4 节：括号不要钱）。
</details>

### 练习 4（挑战层·可选）· 时分秒转换器

**要求**：输入一个总秒数（比如 3665），拆成"X 小时 X 分 X 秒"打印。

💡 提示：这是 `%`（取余）和 `/`（整数除法）的组合拳——3665 ÷ 3600 是小时数（整数除法正好砍掉头），`3665 % 3600` 是剩下的秒数，剩下的再对 60 来一遍。

**自检数据**：`3665` → `1 小时 1 分 5 秒`；`75` → `0 小时 1 分 15 秒`。

<details>参考答案</summary>

```c
#include <stdio.h>

int main() {
    int total, h, m, s;
    printf("请输入总秒数: ");
    scanf("%d", &total);
    h = total / 3600;
    m = (total % 3600) / 60;
    s = total % 60;
    printf("%d 小时 %d 分 %d 秒\n", h, m, s);
    return 0;
}
```

**讲解**：`total % 3600` 取出"扣掉整小时后剩下的零头"，再 `/ 60` 得分钟；`total % 60` 直接就是秒。整数除法在这里从"坑"变成了"工具"——同一个特性，害你还是帮你，取决于你懂不懂它。
</details>

| # | 症状 | 病因 | 解法 |
|---|---|---|---|
| 1 | 输出糊在一行 | 忘了 `\n` | 每句 printf 结尾加 `\n` |

| 7 | 两个 int 变量相除没小数 | 坑看类型不看值 | 强制转换：`(double)a / b` |
| 8 | 变量打出垃圾值 | 没初始化就用 | 定义时顺手 `= 0` |
| 9 | 报错 undeclared | 变量没定义就用/拼错 | 检查定义和拼写 |
