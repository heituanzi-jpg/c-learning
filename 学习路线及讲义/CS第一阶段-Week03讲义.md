## 第 2 章 真与假：计算机的是非观

### 2.1 关系运算符：问问题的工具

判断之前，先要会"问问题"。C 语言问问题的工具叫**关系运算符**，一共 6 个：

| 写法 | 读作 | 例子 | 结果 |
|---|---|---|---|
| `>` | 大于 | `5 > 2` | 真 |
| `<` | 小于 | `5 < 2` | 假 |
| `>=` | 大于等于 | `5 >= 5` | 真 |
| `<=` | 小于等于 | `4 <= 5` | 真 |
| `==` | **等于** | `5 == 5` | 真 |
| `!=` | 不等于 | `5 != 5` | 假 |

⚠️ **本周第一大坑，现在就把预防针打了：**

- `=` 是"装进"（赋值），上周学的
- `==` 才是"等于"（比较），两个等号

写成 `if (age = 18)` 会怎样？**编译器不报错**，但它的意思是"把 18 装进 age，然后当成真"——程序行为完全跑偏，你盯着屏幕两小时都找不到原因。**这是 C 语言历史上坑人最多的一个坑，没有之一。** 记进 mistakes.md 都不过分，先记预防性的一条。

### 2.2 计算机怎么表示"真"和"假"？

计算机没有"真/假"这两个词，它用数字：

- **假 = 0**
- **真 = 任何非 0 的数**（判断的结果统一给 1）

【动手·眼见为实】

```c
#include <stdio.h>

int main() {
    printf("%d\n", 5 > 2);    // 真，打出 1
    printf("%d\n", 5 < 2);    // 假，打出 0
    printf("%d\n", 5 == 5);   // 真，打出 1
    return 0;
}
```

✅ 看到 `1`、`0`、`1`。原来"5 大于 2"这个式子本身就能算出一个值——像 `5 + 2` 算出 7 一样，`5 > 2` 算出 1。**判断式就是一个会算出 0 或 1 的算式**，这个直觉后面天天用。

## 第 3 章 if：给程序装上路标

### 3.1 最基本的 if

```c
int age = 20;

if (age >= 18) {
    printf("成年人\n");
}
```

逐字符拆解：

- `if` = "如果"
- `(age >= 18)` = 路标上的问题，**必须有括号**
- `{ ... }` = 花括号包住的，是"条件为真时才执行"的地盘
- 条件为假？花括号里的内容**整段跳过**，程序直接走到 `}` 之后

### 3.2 else：另一条路

```c
if (age >= 18) {
    printf("成年人\n");
} else {
    printf("未成年\n");
}
```

`else` = "否则"。两条路必走一条，也**只走一条**。

### 3.3 else if：多条路

```c
if (score >= 90) {
    printf("优秀\n");
} else if (score >= 80) {
    printf("良好\n");
} else if (score >= 60) {
    printf("及格\n");
} else {
    printf("不及格\n");
}
```

⚠️ **关键理解：从上到下，逐个检查，第一个为真的执行，其余全部跳过。**

`score = 85` 时：第一个 `>= 90` 假 → 第二个 `>= 80` **真**，打印"良好"→ 后面看都不看。所以条件的**顺序就是优先级**，分数从高往低排，不能乱。

### 3.4 【动手】正负数判断机

建文件（终端：`cd ~/code/c-learning/week03 && touch sign.c && code .`），手敲：

```c
#include <stdio.h>

int main() {
    int num;
    printf("请输入一个整数: ");
    scanf("%d", &num);

    if (num > 0) {
        printf("%d 是正数\n", num);
    } else if (num < 0) {
        printf("%d 是负数\n", num);
    } else {
        printf("这是零\n");
    }
    return 0;
}
```

```bash
gcc sign.c -o sign && ./sign
```

✅ 分别输入 `5`、`-3`、`0` 试三遍，三条路各走一次。**自己输入三组数据把每条路都试到，这个动作叫"测试"，是你今天起的新习惯。**

### 3.5 本节三个坑

**坑 1：if 后面随手加分号。**

```c
if (num > 0);          // ← 这个分号 = "如果为真，就什么都不做"
    printf("正数\n");   // 这行变成无条件执行，永远会打印
```

分号是"一句话说完了"。`if (条件);` 就是一句完整的话——一句废话。**if 的圆括号后面永远没有分号。**

**坑 2：忘记花括号。** if 后面不跟花括号时，只有**紧接着的一行**算它的地盘：

```c
if (num > 0)
    printf("正数\n");
    printf("你输入了非零数\n");   // 这行不属于 if！永远会执行
```

**铁律：哪怕只有一行，也永远写花括号。** 这不是风格问题，是保命问题。

**坑 3：`==` 写成 `=`。** 2.1 打过预防针了，再念一遍：判断相等，两个等号。

## 第 4 章 逻辑运算符：把几个问题连成一串

### 4.1 为什么需要它

现实里的路标经常不止一个问题："**如果**年满 18 **并且**有驾照，才能开车。"——两个条件要同时满足。这时候用**逻辑运算符**把判断式连起来：

| 写法 | 读作 | 生效规则 |
|---|---|---|
| `&&` | 并且 | 两边都真，结果才真 |
| `\|\|` | 或者 | 任一边为真，结果就真 |
| `!` | 取反 | 真变假，假变真 |

```c
if (age >= 18 && has_license == 1) {
    printf("可以开车\n");
}

if (day == 6 || day == 7) {
    printf("周末\n");
}
```

⚠️ 注意：`&&` 是两个 `&`（一个 `&` 是 scanf 里那个取地址，完全不同的东西）；`||` 是两个竖线，键盘上在回车键上方，按住 Shift 敲 `\`。

### 4.2 【动手】合法年龄区间

```c
#include <stdio.h>

int main() {
    int age;
    printf("请输入年龄: ");
    scanf("%d", &age);

    if (age >= 0 && age <= 150) {
        printf("合法年龄\n");
    } else {
        printf("你在逗我\n");
    }
    return 0;
}
```

✅ 输入 `25` → 合法；输入 `-5` 或 `300` → 你在逗我。

**顺手解决上周的遗留坑**：上周说"用户乱输会坏，本周收拾它"——现在你会了：用 if 给输入做"安检"。**所有 scanf 之后跟一句合法性检查，是工程师的肌肉。**

### 4.3 短路： && 和 || 的偷懒机制（知道即可）

- `A && B`：A 为假，B **看都不看**，直接判假
- `A || B`：A 为真，B **看都不看**，直接判真

电脑很懒，能不算就不算。现在只需知道有这回事，以后这个特性会在循环和指针里救你。

### 4.4 嵌套 if：路标里面还有路标

```c
if (age >= 18) {
    if (has_license == 1) {
        printf("可以开车\n");
    } else {
        printf("先考驾照\n");
    }
} else {
    printf("先长大\n");
}
```

效果和 `&&` 版本类似，但结构不同：嵌套 if 是"进了大门再看小门"。**能用 `&&` 连起来的，优先用 `&&`，代码更平。** 嵌套留给"第二层判断只在第一层成立时才有意义"的场景。

## 第 5 章 switch：多路选择的专用路标

### 5.1 什么时候用它

`else if` 链一长，代码就变成斜塔。当判断的形式是"**一个变量，分别等于几个固定值**"时，有专门工具：

```c
int choice;
printf("1.开始游戏 2.读取存档 3.退出\n");
printf("请选择: ");
scanf("%d", &choice);

switch (choice) {
    case 1:
        printf("游戏开始\n");
        break;
    case 2:
        printf("读取存档\n");
        break;
    case 3:
        printf("退出\n");
        break;
    default:
        printf("没有这个选项\n");
        break;
}
```

结构拆解：

- `switch (choice)`：要检查的变量，括号包住
- `case 1:`：如果 choice 等于 1，从这里开始执行
- `break;`：**跳出 switch**。忘了它会出大事，见 5.2
- `default:`：所有 case 都没对上时的兜底，相当于 else

### 5.2 本周第二大坑：忘 break 的"瀑布"

【动手】把上面代码里的 `break` 全删掉，输入 `1`，看看发生什么：

✅ 你会发现从 `case 1` 开始，**下面所有分支的 printf 全部执行了**——像瀑布一样一路流到底。

**规则：case 只是"入口"，不是"房间"。** 进了 case 1 的门，没有 break 拦着，就一路穿过 case 2、case 3……直到 switch 结束。**每个 case 末尾写 break，写到形成条件反射。**

### 5.3 switch vs else if：怎么选

| 场景 | 用什么 |
|---|---|
| 一个变量 == 几个固定值（菜单、星期、选项） | switch，更清爽 |
| 范围判断（>= 90、0~150） | else if，switch 干不了这个 |
| 条件里带 `&&` `\|\|` | else if |

### 5.4 【动手】把正负数判断机改成菜单版（选做）

不难，自己试：用 switch 打印一个菜单，输入 1 判断正负数，输入 2 退出。做出来你会第一次有"我在写一个真正的程序"的感觉。

## 第 6 章 程序员的基本功（本周份）

### 6.1 边界测试：专挑"边上"的值

新手测试：随手输一个 25，对了，收工。
老手测试：**专挑边界**。

判断 `age >= 18`，真正的考验在 **17、18、19** 这三个值上——17 必须走"未成年"，18 必须走"成年"（等号归哪边，一秒见分晓），19 确认没跑偏。

**规矩：写完一个 if，至少测三组：边界值左边、边界值本身、边界值右边。** 上周的自检数据（BMI 的 22.6、温度的 32→0）就是在训练这个直觉。

### 6.2 缩进层级又深了一层

if 套 if，代码就"长楼梯"了：

```c
if (a) {
    if (b) {
        printf("两层\n");
    }
}
```

每一层 `{` 往里缩 4 格（Tab），每一个 `}` 和它所属的 if 对齐。**括号配对看错层，是本周报错的第一来源。** 看花眼了就把光标放在 `{` 上——VS Code 会高亮配对的那个 `}`。

### 6.3 注释写"判断的意图"

```c
// 安检：年龄必须在人类范围内，防止用户乱输
if (age >= 0 && age <= 150) {
```

烂注释：`// if 判断年龄`（废话）。好注释说**为什么这里要拦一道**。

### 6.4 报错新面孔

| 报错关键词 | 大概率是 |
|---|---|
| `expected ')' before ...` | if 的条件括号没关上 |
| `expected statement before '}'` | if 后面多了分号 / 花括号错位 |
| `comparison between pointer and integer` | 忘了 `==` 的另一个坑，少见，遇到发我 |
| 报错指向 switch 某 case | 上一个 case 忘了 break（不报错但行为诡异，更要命） |

### 练习 1（跟做层）· 奇偶判断机

**要求**：输入一个整数，告诉用户是奇数还是偶数。

💡 提示：上周学的 `%`（取余）在这里上班——`n % 2 == 0` 就是偶数。

**手把手**：

① 建文件：`cd ~/code/c-learning/week03 && touch odd_even.c && code .`

② 敲代码：

```c

int main() {
    int n;
    printf("请输入一个整数: ");
    scanf("%d", &n);

    if (n % 2 == 0) {
        printf("%d 是偶数\n", n);
    } else {

```

③ 编译运行：`gcc odd_even.c -o odd_even && ./odd_even`

### 练习 2（半独立层）· 闰年判断机

**要求**：输入年份，判断是不是闰年。

**规则**（这是真实世界的规则，别嫌绕）：能被 4 整除但不能被 100 整除，**或者**能被 400 整除，就是闰年。

💡 提示：把上面的中文一句一句翻译成代码——"能被 4 整除"就是 `year % 4 == 0`，"但不能被 100 整除"用 `&&` 接上 `year % 100 != 0`，"或者"用 `||`。一个 if 搞定，不用嵌套。

**自检数据**：`2024` → 闰年；`1900` → **不是**（能被 100 整除但不能被 400 整除）；`2000` → **是**（能被 400 整除）。

<details>参考答案（做完再点开）</summary>

```c
#include <stdio.h>

int main() {
    int year;
    printf("请输入年份: ");
    scanf("%d", &year);

    if ((year % 4 == 0 && year % 100 != 0) || year % 400 == 0) {
        printf("%d 是闰年\n", year);
    } else {
        printf("%d 不是闰年\n", year);
    }
    return 0;
}
```

**讲解**：注意第一组条件用括号包起来了——`&&` 和 `||` 混用时，括号保命（6.4 节老规矩：括号不要钱）。1900 和 2000 这组对比数据是本题的精髓：测不出来这两个的区别，说明你的条件写漏了一半。
</details>

### 练习 3（独立层）· 🏆 本周主项目：BMI 计算器 v2

**要求**：升级上周的 BMI 计算器——算完之后，自动打印评价：

| BMI | 评价 |
|---|---|
| < 18.5 | 偏瘦 |
| 18.5 ~ 24 | 标准 |
| 24 ~ 28 | 超重 |
| ≥ 28 | 肥胖 |

（"18.5 ~ 24"的意思是 18.5 ≤ BMI < 24，依此类推。）

**验收样子**：

```
请输入身高(米): 1.85
请输入体重(公斤): 77.5
你的 BMI 是 22.6，评价: 标准
```

**自检数据**：1.85/77.5 → 22.6 标准；1.70/50 → 17.3 偏瘦；1.70/90 → 31.1 肥胖。

💡 提示：else if 链，评价从**严到宽**排（先判 < 18.5，再 < 24，再 < 28，最后 else）。想明白为什么这个顺序不能乱，3.3 节有答案。

<details>参考答案（做完再点开）</summary>

```c
#include <stdio.h>

int main() {
    double height, weight, bmi;
    printf("请输入身高(米): ");
    scanf("%lf", &height);
    printf("请输入体重(公斤): ");
    scanf("%lf", &weight);

    bmi = weight / (height * height);

    if (bmi < 18.5) {
        printf("你的 BMI 是 %.1f，评价: 偏瘦\n", bmi);
    } else if (bmi < 24) {
        printf("你的 BMI 是 %.1f，评价: 标准\n", bmi);
    } else if (bmi < 28) {
        printf("你的 BMI 是 %.1f，评价: 超重\n", bmi);
    } else {
        printf("你的 BMI 是 %.1f，评价: 肥胖\n", bmi);
    }
    return 0;
}
```

**讲解**：注意每个条件只写了**上界**——`bmi < 24` 不用写 `bmi >= 18.5 && bmi < 24`，因为能走到这一行，说明 `< 18.5` 已经是假了。这就是 else if "第一个为真后全跳过"带来的免费简化。上周的彩蛋，今天兑现了。
</details>

### 练习 4（挑战层·可选）· 星期菜单

**要求**：switch 写一个菜单：输入 1~5 打印"工作日·第 N 天"，输入 6、7 打印"周末"，其他数字打印"输入有误"。

💡 提示：case 可以**共用**执行内容——`case 1:` 到 `case 5:` 连着写，只在 `case 5:` 后面写 printf 和 break。这正是 5.2"瀑布"的合法用法：故意让 5 个 case 流进同一个出口。

**自检数据**：`3` → 工作日；`6` → 周末；`9` → 输入有误。

<details>参考答案</summary>

```c
#include <stdio.h>

int main() {
    int day;
    printf("请输入星期几(1-7): ");
    scanf("%d", &day);

    switch (day) {
        case 1:
        case 2:
        case 3:
        case 4:
        case 5:
            printf("工作日·第 %d 天\n", day);
            break;
        case 6:
        case 7:
            printf("周末\n");
            break;
        default:
            printf("输入有误\n");
            break;
    }
    return 0;
}
```

**讲解**：case 1~4 什么都不写，直接"瀑布"到 case 5 的处理——这是唯一被允许的忘 break。它和 Bug 的区别只有一个：**是故意的**。
</details>

## 第 8 章 Week 03 验收（3 题 + 1 个硬性条件，交卷发我）

## 第 9 章 本周避坑大全（一页速查，卡住了先翻这页）

| # | 症状 | 病因 | 解法 |
|---|---|---|---|
| 1 | 条件明明为假，代码还是执行了 | if 后面多了分号 | 删掉 `)` 后面的 `;` |
| 2 | if 只有第一行生效，第二行总会跑 | 没写花括号 | 永远写 `{ }`，哪怕一行 |
| 3 | 判断相等永远不生效/行为诡异 | `==` 写成了 `=` | 判断相等，两个等号 |
| 4 | switch 里多个 case 的结果全打出来了 | 忘了 break | 每个 case 末尾补 `break;` |
| 5 | else if 链结果总是"最低档" | 条件从宽到严排了 | 从严到宽，第一个为真全跳过 |
| 6 | `&&` 打出来报错 | 只打了一个 `&` | 逻辑"并且"是两个 `&&` |
| 7 | 边界值（18/60/90）结果错了 | `>` 和 `>=` 用混 | 想清楚等号归哪边，测边界 |
| 8 | 报错 expected ')' | if/switch 的条件括号没关 | 数括号，配对检查 |
| 9 | 输入字母后程序发疯 | 没做输入安检 | scanf 后加合法性 if |
| 10 | 改了代码结果没变 | 没保存 | `Ctrl+S`（老坑复查） |
